# Свадебное приглашение - Эльвина и Руслан

Элегантный сайт-приглашение на свадьбу в оливковых пастельных тонах.

## Особенности

- Адаптивный дизайн для всех устройств
- Обратный отсчет до дня свадьбы
- Интеграция с календарями (Google Calendar, iCal)
- Форма подтверждения присутствия (RSVP)
- Элегантная типографика и анимации
- Премиум дизайн в оливковых тонах

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Montserrat)

## Детали события

- **Дата:** 27 июля 2027
- **Время:** 14:00
- **Место:** Парк Урал Батыр, село Аскарово

## Развертывание

Сайт готов к размещению на любом хостинге:
- Netlify
- Vercel
- GitHub Pages
- Любой статический хостинг

### Для поддомена patatoyes.com

1. Загрузите файлы на хостинг
2. Настройте DNS-записи для поддомена
3. (Опционально) Настройте Formspree для RSVP формы

## RSVP Форма

Текущая версия сохраняет ответы в localStorage браузера.

Для продакшена рекомендуется:
- Формспри (formspree.io) - бесплатно до 50 ответов/месяц
- Netlify Forms - если хостинг на Netlify
- Собственный backend

## Кастомизация

Цветовая схема определена в CSS переменных в `:root`:
- `--primary`: основной оливковый
- `--primary-light`: светлый оливковый
- `--primary-dark`: темный оливковый
- `--accent`: акцентный цвет
